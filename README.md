# NurseConnect

A responsive healthcare staffing website built with Next.js 16, React 19, Tailwind CSS, and accessible Radix UI components.

## Features

- Search and filter nursing opportunities
- Job application workflow
- Healthcare facility staffing request workflow
- Device-persistent submission dashboard
- Responsive desktop and mobile layout
- Privacy and healthcare-data guidance

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
pnpm start
```

The Vercel edition stores submissions in the visitor's browser. Connect a production database such as Supabase or Neon before using it to collect real applications across users or devices.
